# COES Academy — Converged OT/IT Energy Security

A self-paced, interactive OT/ICS cybersecurity training academy for the energy sector
(nuclear, oil & gas, power generation), built on the B.A.S.I.C. S.T.A.R.T. framework.

This is a single self-contained `index.html` (HTML/CSS/JS, no build step). Hosted via GitHub Pages.

- 13 in-depth modules with full lectures, figures, worked examples and knowledge checks
- 12 hands-on blue-team labs on free tools and safe simulators
- A living defender casebook of real energy-sector ICS/OT incidents
- Branching decision scenarios, an OSINT unit, and a 100-question final exam with certificate

Note: the "Ask Cany" tutor uses live AI only on the Claude platform; as a static site it falls
back to built-in canned/navigation answers. All other features run fully client-side.
